# CrossCode Carnellio Mod
Adds a series of optional, challenging bosses utilizing a unique combo system. 
Crossover with Skill Based Boss Fights! (by finalnoobboss)

# Installation
Available in CCModLoader. Just look up the name of the mod!
CCLoader: https://github.com/CCDirectLink/CCLoader

## Currently includes 5 fights/modes:
- Base Carnellio, including all combos in the original fight
- Gwas Combos Carnellio, including all combos from the original fight
- Fate Combos Carnellio, completely new combos including new sigils and OST, courtesy of F6R1 and Materia Music+finalnoobboss respectively
- Random Combos, randomized combos
- Random Fate Combos, randomized combos including the new sigils
